Same contact-tracing question in SQL (PostgreSQL self-join on appointment):
SELECT count(DISTINCT c.patient_id) AS covid_cases, count(DISTINCT o.patient_id) AS exposed_patients, count(*) AS exposure_events
FROM clinic.diagnosis dx
JOIN clinic.appointment c ON c.appointment_id = dx.appointment_id
JOIN clinic.appointment o ON o.doctor_id = c.doctor_id
     AND (o.scheduled_start AT TIME ZONE 'America/New_York')::date = (c.scheduled_start AT TIME ZONE 'America/New_York')::date
     AND o.patient_id <> c.patient_id AND o.status = 'Completed'
     AND o.scheduled_start >= '2026-08-01' AND o.scheduled_start < '2026-10-28'
WHERE dx.icd10_code = 'U07.1' AND c.status = 'Completed'
  AND c.scheduled_start >= '2026-08-01' AND c.scheduled_start < '2026-10-28'
-> covid_cases=1940, exposed_patients=6276, exposure_events=10320  (251.7 ms)
A variable-length path such as G5 needs a WITH RECURSIVE query in SQL that alternates patient and
doctor joins and must track visited nodes to stop cycles - see shortest_path_recursive.sql.
SQL WITH RECURSIVE breadth-first search (shortest_path_recursive.sql) -> hops = 4 (183.9 ms), distance only, no path.
